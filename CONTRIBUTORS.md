## Bantuan AI

[Codex (OpenAI)](https://openai.com/codex/) membantu pengembangan dan dokumentasi, termasuk penyiapan kontribusi komunitas pada repo ini. Atribusi ini dicatat terpisah dari daftar akun GitHub yang dikelola bot.

Atribusi Codex menunjukkan bantuan AI. Tanggung jawab atas perubahan dan keputusan penggabungan tetap pada maintainer manusia.

## Tambahkan kontribusimu

Kontribusi kode, dokumentasi, laporan bug, riset, contoh sintetis, dan review dipersilakan. Ikuti [panduan kontribusi](CONTRIBUTING.md). Untuk meminta pencantuman, tulis komentar pada issue atau pull request terkait, menggunakan username GitHub publik dan jenis kontribusi yang sesuai:

```text
@allcontributors please add @USERNAME for code, doc
```

Bot akan mengajukan pull request untuk memperbarui daftar; maintainer meninjau perubahan sebelum menggabungkannya. Lihat [jenis kontribusi](https://allcontributors.org/en/emoji-key/) dan [panduan bot](https://allcontributors.org/en/bot/usage/). Pencantuman bersifat opsional; riwayat commit dan pull request juga menyimpan atribusi kontribusi.

Perbarui daftar melalui bot atau CLI All Contributors agar tabel dan `.all-contributorsrc` tetap selaras. Teks di luar penanda `ALL-CONTRIBUTORS` tidak dikelola generator.
